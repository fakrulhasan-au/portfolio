ITNE2004 — Wireless Communication & Networks
University Campus WLAN Design — Cisco Packet Tracer
Designed and simulated a full enterprise-grade WLAN for a university campus using Cisco's three-tier hierarchical model (Core, Distribution, Access) in Cisco Packet Tracer. Built a redundant dual-core with two Cisco 3560-24PS Layer 3 switches linked via EtherChannel, three 2960-24TT distribution switches, three access switches, and a Cisco ASA 5505 firewall Deployed a WLC-PT Wireless LAN Controller managing all three access points (Academic, Residence, Outdoor) via CAPWAP tunnels for centralised security and roaming Implemented four VLAN segments: Students (WPA3-Enterprise/802.1X), Staff (WPA3-Enterprise/cert), Guests (captive portal), and IoT (WPA2-PSK/MAC auth) Configured QoS: DSCP EF for VoWiFi, AF41 for e-learning, bandwidth throttling for guests; non-overlapping channels (1, 6, 11) to minimise co-channel interference Documented full scalability plan for Wi-Fi 6E/7 migration and phased AP refresh without infrastructure redesign

ITSC1001 — Information Systems Risk & Security
Equifax Data Breach — Security Risk & Cost Analysis
In-depth case study and security analysis of the 2017 Equifax breach — the largest identity theft incident in history, exposing 147.9 million Americans' personal data. Traced the full attack path: Apache Struts CVE-2017-5638 exploitation (March), lateral movement through poorly segmented systems (May–July), and undetected exfiltration due to an expired SSL certificate Assessed compromised assets: SSNs, birth dates, addresses, 209,000 credit card numbers, and 182,000 dispute documents Identified key vulnerabilities — unpatched software, plaintext password storage, no network segmentation, weak authentication, and third-party risk Quantified financial impact: $1.4B security remediation cost, $1.38B FTC settlement, £11.2M FCA fine, and Moody's credit rating downgrade Produced actionable recommendations: incident response tabletop drills, MFA, patch management, network segmentation, and cybersecurity insurance
